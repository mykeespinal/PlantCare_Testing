## 🌿 ¿Qué es Plant Care?

Plant Care es una guía natural enfocada en plantas medicinales que permite consultar recetas, organizar categorías y administrar el contenido de forma sencilla.

| 🌿 Función | 💚 ¿Qué puedes hacer? |
|:---|:---|
| 👑 Administración | Probar cuentas de administración y gestión del sistema. |
| 👥 Usuarios | Crear y registrar nuevos usuarios desde el panel de control. |
| 📄 Reportes | Descargar el reporte PDF con la lista de usuarios. |
| 📂 Contenido | Crear categorías y registrar nuevas recetas medicinales. |
| 🔍 Exploración | Buscar plantas medicinales y navegar por la aplicación. |
| ⭐ Favoritos | Guardar recetas preferidas y consultarlas rápidamente. |

## 💬 Tu opinión nos importa

Al terminar los diez retos, responde estas tres preguntas adicionales:

**1. 💚 ¿Qué fue lo que más te gustó de Plant Care?**

**2. 🛠️ ¿Qué mejorarías o cambiarías de la aplicación?**

**3. 🌿 ¿Recomendarías esta aplicación a alguien interesado en la medicina natural? ¿Por qué?**

También puedes agregar sugerencias, errores encontrados y capturas de pantalla.

No compartas contraseñas, tokens ni información personal.

## 📤 ¿Cómo entregar tu evaluación?

1. Abre el documento con tu nombre.
2. Completa las diez pruebas.
3. Califica tu experiencia y agrega observaciones.
4. Guarda los cambios en una rama propia.
5. Crea un Pull Request dirigido a `main`.

**Importante:** Cada participante debe editar únicamente su informe. Esta es una instrucción de trabajo; GitHub Free no impide técnicamente la edición directa de `main` en este repositorio privado.
